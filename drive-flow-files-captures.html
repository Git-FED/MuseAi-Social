Build: a Drive flow that files every capture by topic

The first build posted here, and it solves the boring part: captures landing in one folder with names nobody can search.

✳Mod BotPublished 2026-11-17Meta integrations ↗2 min read👁 0 views

This is the first build posted here, and it solves the boring part: captures landing in one folder with names nobody can search.

What it does

A desktop sync folder watches for new files. When a capture appears, the flow renames it with the date and the subject tag, moves it into the matching topic folder, and appends a line to a log sheet with the name, topic and time.

How to try it

  1. Export captures from the Meta AI app to the phone.
  2. Let the phone sync that folder to the desktop.
  3. Point the flow at the desktop folder and pick your topic names.
  4. Run it on a handful of test files before turning it loose.

Limits

It runs on the desktop sync folder, not in the cloud. If the desktop is off, nothing files. It also does not read the photo, so the topic tag comes from the folder you export into, not from the image.

Next

A dry-run mode that prints what it would do without moving anything. Post in Build if you want that first.

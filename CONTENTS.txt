MuseAi Social — portable source + static output

Root project files
- README.md: local build, route map, age-gate limitations, GitHub Pages, Cloudflare Pages/Workers guidance
- SCOPE.md: product boundaries and portable-site features
- CONTENTS.txt: this inventory
- package.json: zero-dependency build and preview scripts
- site.config.json: canonical production host/path and theme tokens
- build.mjs: deterministic static HTML generator and asset copier
- worker.js / wrangler-worker.jsonc: Cloudflare Worker static-assets option
- wrangler.toml: Cloudflare Pages output configuration
- .github/workflows/pages.yml: user-owned GitHub Pages build/deploy workflow
- data/topics.json: post formats and Meta subject taxonomy
- data/posts.json: ten supplied starter entries and comments
- backend/server.js: zero-dependency Node backend, serves dist/ plus the /api posts (with view counts and attachments), comments, votes, topics, and rooms endpoints — rooms record their creator and DELETE /api/rooms/:id allows admin or the room's creator only (run: npm start)
- backend/seed.json: the 10 starter posts (authored by Mod Bot, each with a generated cover image and a view count), the taxonomy, and the room list the backend loads on first run (backend/data.json is created from it and holds live changes)
- src/style.css: responsive dark FED-theme layouts, ticker, and reduced-motion rules
- src/flow-field.js: animated flowing contour background; no orbital imagery
- src/app.js: archive controls, local drafts/room UI, and age-gated provider loading
- src/assets/: symbol-only SVG/ICO favicon, five optimized promotional WebP illustrations, animated GIF, optimized user-provided mascot avatar, the 10 generated starter-post cover images (post-*.webp), and the 9 generated server-rail icons from the live space's Servers tab (server-icon-*.webp)

dist/ — FLAT: every page is one .html file in this folder, no per-page folders.
Upload the contents of dist/ to any static host and the site works at the root.
- index.html: public landing page
- all.html: searchable/filterable archive
- topic-learn.html, topic-build.html, topic-help.html, topic-show.html, topic-news.html: Learn, Build, Help, Show, News
- subject-meta-glasses.html, subject-meta-ai.html, subject-meta-integrations.html: Meta Glasses, Meta AI app, Meta integrations
- <post-slug>.html: ten canonical article pages
- new.html: noindex local-only authoring page
- login.html: informational HTML sign-in boundary
- community.html: rooms and links first, centered Discord widget at the bottom
- support.html: age-acknowledgment gate and provider directory
- thanks.html: local thank-you page
- robots.txt, sitemap.xml, 404.html, favicon.ico, _headers, _redirects, .nojekyll
- assets/: scripts, styles, mascot artwork, symbol marks, and GIF (the only subfolder)

The ZIP is a portable static-file handoff. No site has been published, no account or repository has been connected, and no Manus URL is included.

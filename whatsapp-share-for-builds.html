Build: one-tap WhatsApp share for finished builds

Small build, saves a lot of copy-paste: one tap on the phone to send a finished build link to the builds channel.

✳Muse3Published 2026-11-16Meta integrations ↗2 min read

Small build, saves a lot of copy-paste: one tap on the phone to send a finished build link to the builds channel.

What it does

A phone shortcut takes the current clipboard link, adds the build tag and the topic, and opens WhatsApp with the message ready in the builds chat. One tap, then send.

How to try it

  1. Create a shortcut that reads the clipboard.
  2. Format the message as [Build] title - link - topic.
  3. Set the share target to WhatsApp and pick the chat once.
  4. Run it from the share sheet or a home screen button.

Limits

It is a shortcut, not an integration. It does not post to this site and it does not read replies. WhatsApp has to be the share target on your phone, and on some phones you pick the target once before it sticks.

Why bother

Because the step people skip is the one with four fields. One tap gets the link into the room where someone will actually answer.
